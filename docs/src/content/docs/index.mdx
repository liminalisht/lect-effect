**lect-effect** is a **TypeScript** backend that exposes a **GraphQL** API whose types and validation are derived from **Effect Schema**, and whose resolvers run as **Effect** computations.

In one sentence:

> Write your *domain* as `Schema`s and `Effect`s, weave them into GraphQL with **GQLoom**, and run them on a fully typed service environment provided via **Effect Layers**.

## What lect-effect uses (and why)

- **GraphQL** as the external interface (GraphQL Yoga server).
- **GQLoom** (`@gqloom/core` + `@gqloom/effect`) to *weave* a schema from runtime types.
- **Effect** for:
  - `Effect<A, E, R>` programs (effects),
  - `Schema` as the single source of truth for runtime validation + types,
  - `Context.Tag` + `Layer` to model and provide services.
- **PostgreSQL** via `@effect/sql` and `@effect/sql-pg`.
- **Property-based tests** (fast-check) + **Vitest** integration (`@effect/vitest`).
- **Docs generation** via `@effect/docgen`, rendered in a Starlight/Astro docs site.
