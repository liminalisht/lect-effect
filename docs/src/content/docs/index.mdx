**lect-effect** is a **TypeScript** backend that exposes a **[GraphQL](https://graphql.org/)** API whose types and validation are derived from **[Effect Schema](https://effect.website/docs/schema/introduction/)**, and whose resolvers run as **[Effect](https://effect.website/docs/getting-started/introduction/)** computations.

:::tip[tl;dr]
Write your *domain* as `Schema`s and `Effect`s, weave them into GraphQL with **[GQLoom](https://gqloom.dev/)**, and run them on a fully typed service environment provided via **[Effect Layers](https://effect.website/docs/requirements-management/layers/)**.
:::
